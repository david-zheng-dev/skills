# Changesets

This folder has been automatically generated by `@changesets/cli`, a build tool that works
with single-package repos to help you version and release your code. You can find the full
documentation for it [in the changesets repository](https://github.com/changesets/changesets).

## How to add a changeset

When you make changes that should trigger a version bump, run:

```bash
npx changeset
```

This will ask you:
1. Which package(s) to bump — select `nimbus-skills`.
2. What kind of bump — `patch` / `minor` / `major`.
3. A short description of the change (this goes into CHANGELOG.md).

A changeset file (e.g. `.changeset/odd-tigers-smile.md`) is created. Commit it with your work.

## How to release a version

When you are ready to cut a release, run:

```bash
npm run version
```

This consumes all pending changesets, bumps `package.json`'s `version`, regenerates
`CHANGELOG.md`, and runs `scripts/sync-plugin-version.mjs` to copy the new version into
`.claude-plugin/plugin.json`. Then commit the result and tag/publish as usual.

## CI guard

`npm run check-plugin-version` verifies that `.claude-plugin/plugin.json`'s `version` matches
`package.json`'s `version`. Wire this into CI so a forgotten sync fails the build.
